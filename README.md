Language Tutor

An Android application for learning English and preparing for IELTS exams. The app features vocabulary training, exam preparation, progress tracking, and personalized learning paths.
Features

Main Screen

Browse English language courses for different levels
Free course for beginners
Intermediate course (60$ / 30150 tenge)
IELTS preparation course (180$ / 90450 tenge)
Native speaker-led instruction

Statistics 

Weekly and monthly study time tracking
Visual progress charts
Current level tracking (e.g., B2)
IELTS score monitoring
Total time spent learning

Exam Section 

Mock IELTS tests
Level assessment (A1-C2)

Practice modules:

Reading
Listening
Writing
Speaking



Memorization Tool 

Vocabulary training system
Russian-English word pairs
Progressive learning approach
Spaced repetition methodology

Technical Requirements

Android 6.0 (API level 23) or higher
Internet connection for course access
Minimum 100MB storage space

Installation

Download the APK from the releases section
Enable installation from unknown sources in your device settings
Install the application
Launch and begin learning
